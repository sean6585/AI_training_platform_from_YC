載入已標註資料集（data.yaml）

已標好的 YOLO 資料集不必複製進本程式。選擇 data.yaml，Server 依 yaml 內的路徑就地讀取，訓練時也直接餵這份 yaml——全程零複製。

資料集資料夾結構
DATASET_ROOT/
├── data.yaml
├── images/
│   ├── train/   img001.jpg  img002.jpg ...
│   └── val/     img101.jpg ...
└── labels/
    ├── train/   img001.txt  img002.txt ...   # 檔名需與圖片相同
    └── val/     img101.txt ...
data.yaml 內容
path: /home/user/datasets/PPE   # 可省略，省略時相對路徑以 yaml 所在位置為基準
train: images/train
val: images/val
names:                          # 順序即類別編號 0, 1, 2 ...
  0: Hardhat
  1: NO-Hardhat
  2: Safety-Vest

合併外部資料集（Merge External Dataset）

從其他來源（例如另一個 YOLO 模型輸出的標註）匯入影像與標籤。外部資料集的類別編號通常和目前這份不同，讀取 yaml 後可在下方逐一對應。合併時會把來源影像整包複製到 DefectMaster_Output/.merged/ 下的新資料夾，只有重新編號後的 .txt 是新寫出的——原始資料夾與其 data.yaml 完全不會被更動，而且隨時可「移除此來源」還原。

在測試集上評估

用訓練時完全沒看過的圖片驗證一個模型，不影響訓練：資料集頁套用切分產生的 test 集，或在標註頁手動移到測試圖片資料夾的圖片（只計已標註的）。

通常幾十秒到幾分鐘內完成，視測試集大小與硬體而定。
◎

推論測試

TensorRT engine 推論子行程閒置 180 秒後自動結束並歸還記憶體。模型清單依訓練時間排序，最新的在最上面。
▦

批次推論

一次推論整個資料夾（例如 test 資料夾），使用上方選的模型與信心門檻。 效果不好的圖按「加入訓練集」：會複製一份到目前資料集的訓練資料夾，並把模型的預測框帶進去當預標註， 再到「標註工具」頁（篩選「從推論加入」）修正。原始圖片不會被移動或修改。
